# 🌿 Marigold Trail – Village Treasure Hunt Adventure Game

**Follow the clues. Brave the unknown. Find the lost gold.**

## 📖 About the Project

Marigold Trail is an interactive, village-themed treasure-hunt adventure game where players explore mysterious locations, solve puzzles, discover hidden clues, and unlock new levels to find a legendary treasure.

The game combines exploration, word searches, riddles, logic challenges, danger zones, and rewards to create an engaging gaming experience.

## 🎯 Objectives

- Create an interactive village exploration game.
- Design multiple levels with unique challenges.
- Implement an unlockable village map.
- Add puzzles, riddles, and hidden-word challenges.
- Introduce danger zones, health points, and collectible coins.
- Provide a journal to track discovered clues.
- Create a rewarding final treasure-discovery experience.

## 🎮 Game Features

- **Interactive Village Map:** Explore locations and unlock new destinations.
- **Progressive Levels:** Complete challenges to advance through the adventure.
- **Word Search:** Discover hidden words to reveal clues.
- **Riddles and Logic Puzzles:** Solve challenges to progress.
- **Danger Zones:** Navigate hazards and find safe routes.
- **Health System:** Monitor health while exploring dangerous areas.
- **Coins and Rewards:** Collect coins and earn rewards by completing challenges.
- **Clue Journal:** Review discovered clues and objectives.
- **In-Game Market:** Purchase available hints or useful items.
- **Progress Saving:** Continue the adventure from saved progress, if implemented.
- **Final Treasure:** Complete the adventure by solving the final challenge.

## 🗺️ Game Levels

| Level | Location | Main Challenge |
|---|---|---|
| 1 | Village Gate | Introductory riddle |
| 2 | Barn Loft | Word-search puzzle |
| 3 | Whispering Woods | Route selection and clue discovery |
| 4 | Bramble Crossing | Danger-zone navigation |
| 5 | Forgotten Well | Number and symbol puzzles |
| 6 | Shepherd's Meadow | Memory and landmark matching |
| 7 | Hidden Ruins | Multi-step clue-solving |
| 8 | Golden Chest | Final treasure puzzle |

## 🕹️ How to Play

1. Start a new game or continue an existing adventure.
2. Explore the village map.
3. Select an unlocked location.
4. Read the objective and inspect the available clues.
5. Solve the puzzle or complete the location's challenge.
6. Collect rewards and update your journal.
7. Unlock the next location and continue exploring.
8. Complete the final challenge to discover the treasure.
